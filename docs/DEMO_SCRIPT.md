# 3–5 Minute Demo

1. Introduce the problem: flight prices vary across route, airline, class, stops and booking lead time.
2. Show dataset overview and cleaning decisions.
3. Show five visualizations in the Exploration tab.
4. Show MAE, RMSE, R² and feature importance.
5. Open Cheapest Booking and select a route/airline/class.
6. Explain that the recommendation is historical, uses a minimum sample threshold and is not a guarantee.
7. Show source code, tests, GitHub Actions and README.
8. Close by explaining the engineering decisions you personally understand.
